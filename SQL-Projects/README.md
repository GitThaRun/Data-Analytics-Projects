# SQL Projects

This folder contains data analysis projects built using SQL.

The projects focus on applying SQL as a practical business analysis tool for:

- Data Exploration
- Data Filtering
- Data Aggregation
- Data Transformation
- Business Metrics
- Business Insights Generation

---

# Skills Practiced

Projects in this section are designed to strengthen practical SQL skills including:

- SELECT & Filtering
- Aggregate Functions
- GROUP BY & HAVING
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Date & Time Functions
- String & Numeric Functions
- Views
- Analytical Queries

---

# Purpose

The goal of these projects is to simulate practical business analysis scenarios and develop the ability to solve business problems using SQL.

Each project is organized in its own folder with:

- SQL query files
- Dataset files where applicable
- Project-specific documentation
