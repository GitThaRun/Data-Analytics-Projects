# Layoffs Data Cleaning

This project focuses on cleaning and standardizing a layoffs dataset using MySQL.

The project demonstrates a practical SQL data-cleaning workflow for preparing raw data for further analysis.

---

# Objectives

The project focuses on:

- Identifying and removing duplicate records
- Standardizing inconsistent data
- Handling NULL and blank values
- Converting data types
- Removing unusable records
- Preparing a clean dataset for analysis

---

# Skills Practiced

- CTEs
- Window Functions
- ROW_NUMBER()
- Self Joins
- UPDATE
- DELETE
- ALTER TABLE
- Data Type Conversion
- String Functions
- Date Functions
- NULL Handling

---

# Data Cleaning Process

```text
Raw Data
   ↓
Create Staging Table
   ↓
Identify Duplicates
   ↓
Remove Duplicates
   ↓
Standardize Data
   ↓
Handle NULL / Blank Values
   ↓
Remove Unusable Records
   ↓
Final Clean Dataset
---
```
